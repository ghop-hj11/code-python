# code-python
code-python studio

欢迎你们加入这个团队！

我们是干什么的？
我们是一个专注于 Python 开发、传播的团队。

项目开源吗？
完全开源！

我不会，但是我有兴趣学 Python，我能加入吗？
可以加入，加入以后慢慢学就行。

我可以用其他语言写项目吗？
可以，你可以让他们和 Python 一起工作，或者辅助 Python。

我们现在缺哪些岗位：
1. 开发人员
2. 跑测试和调试代码的
3. 宣传的
4. 维护秩序的
5. 面对没有加入工作室的人，答疑解惑的

无论你来自哪个国家，会不会编程，你会说什么语言，无论你老或年轻或残疾或健全，无论男女老少，我们都同意你们加入。

怎么加入我们？（三步搞定）

1. 先到我们的 GitHub 仓库看一眼
      地址：github.com/code-python/code-python
      点个 ⭐ Star，再点一下 Fork（把代码复制到你自己的账号下）。
2. 在 Discussions 里发一篇自我介绍
      进入仓库的 Discussions 板块，点击「New discussion」，选择「General」类别。
      标题写：我想加入 code-python – [你的 GitHub ID]
      内容可以参考下面的模板（直接复制粘贴，填上你的信息就行）：
   · GitHub ID：________
   · 所在时区：________（方便我们协调沟通）
   · Python 水平：□ 零基础  □ 刚入门 □ 能写小工具  □ 熟悉框架
   · 最想参与的方向：□ 写代码  □ 写文档  □ 测试  □ 设计  □ 社区管理
   · 每周大概能贡献的时间：________ 小时
   · 一句话介绍自己：________
3. 等着我们联系你
      我们会在一周内回复你的帖子，根据你的兴趣和水平，给你分配第一个「新手任务」（通常是修文档、写测试或者改一个小 bug）。
      之后你就可以正式参与进来，一步步成为核心成员。
没有笔试、没有面试、没有简历筛选。
只要你愿意，我们就愿意带你。

Welcome to join our team!

Completely open source!

Absolutely – you can join and learn along the way.

Yes – you can make them work together with Python, or use them to assist Python.What roles do we currently need?

1. Developers
2. Testers and debuggers
3. Promoters / marketers
4. Moderators (to keep the community orderly)

No matter which country you come from, whether you can code or not, what language you speak, whether you are old or young, with disabilities or not, male or female – we welcome everyone.
How to join us? (Three easy steps)

1. Visit our GitHub repository
      Go to: github.com/code-python/code-python
      Give us a ⭐ Star, and then click Fork (this copies the repo to your own account).
2. Introduce yourself in Discussions
      Go to the Discussions tab of the repo, click «New discussion» and choose the «General» category.
      Title it: I want to join code-python – [your GitHub ID]
      Feel free to copy and paste the template below, filling in your own details:
   · GitHub ID: ________
   · Timezone: ________ (so we can coordinate)· Python level: □ absolute beginner □ just started □ can write small tools □ familiar with frameworks
   · What I'd most like to work on: □ coding □ documentation □ testing □ design □ community management
   · Approximate hours I can contribute per week: ________
   · A one‑sentence intro about myself: ________
3. Wait for us to get back to you
      We'll reply to your post within a week. Based on your interests and skill level, we'll assign your first beginner‑friendly task (usually documentation, writing a test, or fixing a small bug).From there, you can officially start contributing and gradually grow into a core member.

No written tests, no interviews, no CV screening.
If you're willing, we're willing to guide you.
